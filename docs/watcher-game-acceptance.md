# 守望者 0.2.3 实机验收

截至 2026-11-01，本清单是后续可选实机验收项目，不是通过记录。本轮按用户要求未启动游戏或测试存档。将来实测时使用独立存档，记录游戏版本、启用的 Mod、复制人原姓名/InstanceID/技能/特性/日程，以及对应 Player.log。不要与工坊旧版同时启用。

1. **升级与建造**：0.1.7 旧存档中的复活仓、原有病人进度、材料剩余需求和补货保持；同一 Mod 的医疗菜单出现新救援站，MedicineIV 解锁，尺寸/材料/供电正常。
2. **不误抓**：低血量但可行动、正常睡觉、疲劳睡倒、憋气、正在受热和仍可工作的受困者均不出动。真正受伤失能与窒息失能分别测试；仿生目标不出动。
3. **基础救援**：机器人实际离站、到达目标、装载、带人返回；患者显示来自同一姓名/肤色/发型/衣服，不能出现通用人偶、双人或远程瞬移。
4. **航路**：断梯、深坑、无地板竖井、真空、高温蒸汽、岩浆内目标。实体墙、地图边界、不同星球不能穿越；打开/关闭/自动门正在关闭时逐步检查。运输中堵住道路，机器人应保留患者并等待可解释的重新寻路，通道恢复后继续。
5. **急救与原医疗**：受伤倒地者急救至 30% 后停止；高血量窒息者不能被降血，不免费加满饱食/精力。不允许遗体走活体急救。无正式医疗床仍能接回；安全出口无氧、过热、积液或被堵时不强制放人。释放后可正常接受原版医疗、呼吸、工作和受伤，保护不得残留。
6. **保护与电力**：装载后不继续因原环境受烫伤或倒地计时死亡；尚未装载者仍按原版进展。出发前断电不出动，装载后断电保留应急返航，站内断电暂停急救。检查系统其他普通复制人的伤害/死亡不受保护补丁影响。
7. **遗体交接**：已有遗体可以回收；接近时死亡重新分类；运输中死亡或遗体位满不删除。无复活仓、仓满、仓被拆或门被堵时保留遗体并提示。可接收时，机器人实际飞到仓旁再交接；保留原技能/特性与复活次数，不重复收费、不抢占已被人工安排的病人。
8. **多站与原生搬运**：两站同时发现同一人只能一站领取。复制人正在搬运/遗体已有预约时不抢夺。急救位与遗体位分别满、同时有活人与遗体时，容量和优先级正确。无电/无路/满载且存在危重目标时有可见报警，无持续刷屏。
9. **保存与读档**：分别在待机、出发、携带活人、急救、出口被堵、遗体暂存、遗体送仓途中保存退出重进。检查原身份始终只有一份、任务继续/合理重规划、不出现落在打印仓的孤儿人物或永久预约。
10. **取消与销毁**：空站可拆，载人/收容时普通拆除受限。强制破坏时检查紧急托管实体保留原患者；拆毁点附近没有安全地面时不得删除或随意释放到岩浆。保存读档后可继续回收/释放；紧急托管不造成无限复制。
11. **显示与性能**：站体急救床、停机位、实际机器人、横卧伤员姿势、图标及中文状态正确。多站稳定运行时没有每帧全图寻路/查找建筑、重派任务或日志刷屏。
12. **医疗交互修订**：床上已有患者时再次出勤，床上人物不消失；遗体不显示在病床上。吊篮位于机身下方，护盾遮住下半身但不挡头；护栏与检查灯不穿过人物头部。拾取、回站交接、向重建仓卸载分别在动作中途保存/加载/暂停/断电，不出现提前换位、重复交接、失去保护或重复治疗。两格净空通道可通行，一格高洞口、底部实体和正在关闭的门阻止吊篮通过。急救完成后落在建筑两侧安全地面。
13. **0.2.3 人物动作**：检查真实患者的发型、头部、服饰、镜像方向和颜色；确认拾取/放床/入床/治疗/起身均有肢体动作，临时显示代理不增加真实复制人。手动释放未治愈者不站起、不加血；遗体保持死亡。双姿态渐变在实际透明材质中没有不合预期的遮挡或残影。
14. **进度与终点**：在入床、出床、受阻反向、返回 0 末帧及手动姿态渐变中暂停/保存/读档。确认原患者一直由同一 Storage 托管，出口临时被堵或断电不提前解除保护；返回 0 后显示衔接稳定。实际释放后恢复原生 AI，没有永久动画覆盖、无敌或第二份身份。

当前操作边界：遗体送仓途中航路长期阻断时，机器人保留遗体及该仓预约。可在目标复活仓取消本次入仓安排，让机器人确认取消后返航；暂未提供救援站端的送仓改派按钮。单次路线搜索有 20,000 格预算，超出预算时也会报告航路受阻，不能将其解释为数学上确定不可达。

将逐项结果、截图（游戏实际截图）和日志位置填写到新的验收记录，不覆盖本清单的“待执行”性质。
