# 守望者 0.2.3 正式素材与人物交互

## 人物动作（0.2.3）

人物不再固定在横卧帧 0。救援站使用原版失能动画的 pickup、carry_loop、place，及原版医疗床的 working_pre 后十帧、working_loop、working_pst。动作保留真实人物的头部、手臂、躯干、腿部及服饰符号；不另造替代身份。

放床与治疗姿态采用不同的原生头部透视，直接切换会跳变。入床阶段保存独立进度，先依据原生头部完整四边形配准，再逐步过渡到医疗姿态；只修改视觉代理自身的 navMatrix，不修改原版全局骨架帧。普通段恢复默认矩阵。原复活仓继续走原来的默认 Show 入口。

拾取记录原人物的世界显示原点、比例和镜像方向；机载、床上、遗体手动出站使用独立代理。镜像人物在卸载前做短暂转向。30 秒付费急救对应八次人物治疗循环，结束时从相同循环接点进入起身。入床未完成不计急救时间，出床期间不继续推进治疗。

离床是独立保存阶段：完整动作结束并保持末帧后才恢复/释放真实人物；只允许站体同层两侧相邻、具备地板和两格净空的安全出口，逐格检查实际直线通道。出口变化时反向回床，到 0 也保留末帧再结束。未治愈者的手动释放使用 place 后半段，遗体全程保持死亡姿态，不提供免费复活。

手动释放开始的短暂阶段在两份原生身体姿态之间渐变，此时不向出口移动；渐变结束才继续放下动作。返床反向使用同一过程，在末端恢复原来的病床姿态。渐变对象只有显示组件，没有复制人身份或保存实体，不会增加真实患者。

`preview/watcher-human-cycle.gif`、`watcher-human-mirrored.gif` 显示正常/镜像动作；`watcher-human-emergency.gif` 显示手动释放；`watcher-human-return.gif` 和 `watcher-human-emergency-return.gif` 显示反向回床资源。后两项展示动作反播接点，不模拟实际地图阻挡事件。人物外观是本机原版默认符号，游戏中仍从患者复制实际外观。

离线渲染直接读取本机 ANIM/BILD 的原始骨架矩阵与符号边界，并调用生产 C# 选帧和位置求解器。没有把游戏人物贴图或骨架字节作为运行依赖打包；运行时引用游戏自带资源。Kanimal 将 SCML 坐标/尺寸乘 2 写入原生资源，控制器使用 .005 世界单位/原生单位；站体 800 原生单位对应 4 格，机器人 360 对应 1.8 格。

`watcher-human-evidence.json` 记录生产源码、原版动画哈希、相对骨骼运动和首尾接点误差。审核结论与未覆盖项目见 `watcher-interaction-review.md`；这些预览不等同于 Unity 内实际播放、服饰和存档验收。

## 建筑与机器人素材（沿用 0.2.2）

本版采用开放式医疗急救站：薄荷色病床、检查灯、监护立柱、旁侧停机位与下挂救援吊篮。粗深色描边、简化明暗和夸张部件比例用于靠近缺氧画风。透明原画由内置 imagegen 生成，保存在 `art/source/watcher_v3/production-parts.png`；导入脚本裁切、归一并编译原生分层动画。

## 动作与绑定

- 救援站：检查灯活动、护栏下降、吊篮至病床交接、付费急救动作、侧向安全释放，以及标准建筑片段。
- 机器人：风扇活动、吊篮降低、护盾分开与闭合、载人飞行、卸载和停靠。
- 每组 KAnim 共 38 个片段：19 个主体/附件片段及 19 个对应 `fg_` 前景片段。前景护栏、下部托管舱盖与吊篮护盾分别遮挡运行时人物。别名不代表新增玩法。
- 实际拾取后立即保护原对象，保留 1.2 秒拾取动作再飞行；回站后保留机载托管，完成 1.2 秒交接才移入病床或遗体位；向重建仓交付也先完成卸载等待。动作类型与剩余模拟时间参与保存。
- 床上人物与机载人物使用两个独立显示对象，保留真实原有外观与颜色；遗体位不显示成病床上的活人。原复活仓默认姿势和着色保留。
- 飞行同时检查机身所在格和下挂吊篮所在格，拾取在目标上方悬停。安全释放点在建筑两侧、占地列之外；缺少安全环境时继续托管保护。

人物附件点与交接路径来自同一组原生动画符号。当前检查覆盖编译、原生反导出和静态时序契约；未启动游戏，不能据此声称 Unity 内的人物姿势、遮挡和所有动态情况已验收。

这些图和帧来自实际编译进安装包的素材，不是另一套概念图；未包含运行时人物叠加，也不是游戏截图。

## 构建

1. `python tools/build-watcher-assets.py --kanimal <kanimal-cli.exe>` 生成分层精灵、SCML 和原生资源。
2. 用 Kanimal `scml` 将每组 PNG/build.bytes/anim.bytes 导出到独立目录。
3. `python tools/build-watcher-assets.py --verify-only --render-native <目录>` 核对片段、真实部件运动、逐帧仿射变换、透明度和颜色，再从反导出文件制作预览。

整个流程不启动游戏或测试存档。素材检查、源码/接口检查与游戏内验收不相互替代。
